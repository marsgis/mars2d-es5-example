# malihu Custom Scrollbar
jQuery 自定义滚动条插件

## 简要介绍
提供样式可定制的自定义滚动条，内嵌 jquery-mousewheel。

## 相关地址
- github地址：https://github.com/malihu/malihu-custom-scrollbar-plugin

## 本地版本信息
3.x（mousewheel 3.1.13）

## 本地文件说明
目录内文件：`jquery.mCustomScrollbar.css`、`jquery.mCustomScrollbar.js`、`LICENSE`、`mCSB_buttons.png`
