# marsgis-editor
MarsGIS 示例页面在线编辑器组件

## 简要介绍
火星科技自研的示例代码在线编辑/运行组件，用于功能示例页面的代码查看、编辑与调试；提供 iife 与 umd 两种构建产物及配套样式。

## 相关地址
- 官网地址：http://mars3d.cn
- github地址：https://github.com/marsgis/mars3d

## 本地版本信息
见源文件（构建产物未内嵌版本号）

## 本地文件说明
目录内文件：`editor.css`、`editor.iife.js`、`editor.umd.js`
