# Monaco Editor
VS Code 同源的浏览器端代码编辑器

## 简要介绍
Microsoft 开源，提供语法高亮、智能提示、差异对比等编辑器能力（codicon.ttf 字体为 CC BY 4.0）。

## 相关地址
- 官网地址：https://microsoft.github.io/monaco-editor
- github地址：https://github.com/microsoft/monaco-editor

## 本地版本信息
0.32.1

## 本地文件说明
含 `base/`、`basic-languages/`、`editor/`、`language/` 子目录。
目录内文件：`LICENSE`、`loader.js`
