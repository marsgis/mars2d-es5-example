# bootstrap-table
Bootstrap 数据表格插件

## 简要介绍
提供排序、分页、勾选、卡片视图等数据表格能力；`extensions/export/` 为导出扩展（见子目录）。

## 相关地址
- 官网地址：https://bootstrap-table.com
- github地址：https://github.com/wenzhixin/bootstrap-table

## 本地版本信息
见源文件头

## 本地文件说明
含 `extensions/`、`locale/` 子目录。
目录内文件：`bootstrap-table.css`、`bootstrap-table.js`、`bootstrap-table.min.js`、`LICENSE`
