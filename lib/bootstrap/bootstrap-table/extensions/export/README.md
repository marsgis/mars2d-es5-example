# tableExport.jquery.plugin + bootstrap-table-export
bootstrap-table 表格数据导出扩展

## 简要介绍
由 tableExport.jquery.plugin（hhurz）与 bootstrap-table 的 export 扩展（zhixin wen / Giri Raj）组成，支持导出 CSV/Excel 等。
