# bootstrap-select
Bootstrap 下拉选择框增强插件

## 简要介绍
为 Bootstrap 原生 select 提供搜索、多选、分组、国际化等增强能力。

## 相关地址
- 官网地址：https://developer.snapappointments.com/bootstrap-select
- github地址：https://github.com/snapappointments/bootstrap-select

1.10.0
