# Bootstrap
Twitter 开源的前端 UI 框架

## 简要介绍
提供栅格系统、全局样式与常用 UI 组件；配套 Glyphicons Halflings 字体位于 `../fonts/` 目录，并随目录收录 select/slider/table/checkbox 等 jQuery 扩展插件（见子目录）。

## 相关地址
- 官网地址：https://getbootstrap.com
- github地址：https://github.com/twbs/bootstrap

## 本地版本信息
3.3.6（bootstrap.js 文件头版本）；`bootstrap.css` 为木遥定制版（文件头标注 UI v1.1.0 / Muyao License 1.0），非 Bootstrap 原版样式

## 本地文件说明
内含 `bootstrap-select/`、`bootstrap-slider/`、`bootstrap-table/`、`bootstrap-checkbox/` 等子目录。
目录内文件：`bootstrap.css`、`bootstrap.js`、`bootstrap.min.js`、`LICENSE`
