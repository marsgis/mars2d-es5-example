# Summernote
基于 jQuery 的所见即所得富文本编辑器

## 简要介绍
提供轻量富文本编辑能力。

## 相关地址
- 官网地址：https://summernote.org
- github地址：https://github.com/summernote/summernote

## 本地版本信息
0.6.3

## 本地文件说明
含 `lang/` 子目录。
目录内文件：`LICENSE`、`summernote.css`、`summernote.js`、`summernote.min.js`
