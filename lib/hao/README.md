# haoutil（hao）
常用 JS 静态方法类库

## 简要介绍
木遥开发的 JavaScript 常用静态方法工具库（全局对象 `haoutil`），提供字符串、数组、日期、坐标转换等常用辅助方法。

## 相关地址
- github地址：https://github.com/muyao1987/haoutil

## 本地版本信息
v2.5.4（编译日期 2021-10-22）

## 本地文件说明
`haoutil.js` 为压缩版，`haoutil-src.js` 为源码版。
目录内文件：`haoutil.js`、`haoutil-src.js`
